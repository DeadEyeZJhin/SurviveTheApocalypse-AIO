# Survive the Apocalypse All-in-One (executor version)

Run this in your executor (or put it in its autoexec folder). It always loads the newest build:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/DeadEyeZJhin/SurviveTheApocalypse-AIO/main/SurviveTheApocalypse_AIO_Executor.lua"))()
```

Keys: Right Alt shows / hides the menu, V = Speed, N = Noclip. Kill Aura key: Middle mouse (changeable in the menu).

Use at your own risk: the game has an anti-cheat.
